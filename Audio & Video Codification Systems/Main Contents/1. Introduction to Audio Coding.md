## Sampling Theorem - *Frequency sampling*
*Exact reconstruction is possible when $f_{S} > 2f_{max}$*. If this is not verified, **spectras overlap, and aliasing occurs**
![[1-Introduction-to-audio-coding.pdf#page=7&rect=238,66,710,403|1-Introduction-to-audio-coding, p.7]]

## Quantization - *Amplitude Sampling*
Measured in bits, it determines the $2^b$ possible amplitude values. Commonly referred to as **bits / sample**

- More bits = more levels = lower quantization noise
- Perceptual coders place noise where it's less audible

## Raw PCM bit rate
$$\text{bit rate (kbps)} = channels·\text{bit depth}·\text{sampling rate}$$
- Channels: Stereo or mono

# The perceptual coding principle
Once a tone is played, the frequencies around it will be "masked", that is, they won't be heard as long as the original tone is still active. We can take advantage of this for lossless quantization
![[1-Introduction-to-audio-coding.pdf#page=11&rect=15,99,851,408|1-Introduction-to-audio-coding, p.11]]

# Audio Coder Attributes & Families
Their main attributes are:
- Quality
- Bit rate
- Complexity
- Delay
- Robustness

With the familites being
- *Lossless*: Exact reconstruction (FLAC)
- *Predictive*: Exploit short/long-term correlation / Speech oriented
- *Transform* / *subband*: Time-frequency coefficients, used in MPEG coders
- *Sinusoidal* / *Parametric*: Represent sound by model parameters 
- *Neural*: Learned analysis / synthesis and quantization - **They're black boxes**
