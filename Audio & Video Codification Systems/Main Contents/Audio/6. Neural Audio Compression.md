# Stride and panning in CNNs
**STRIDE**: Hop size between the filters
	Larger strides reduces the number of output frames and can contribute to compression
**PADDING**: Extra samples around the input (usually zero)
	Padding controls the output size and avoids losing boundary information.

# Encoders in audio compression
- Series of convolutional layers compresses the input audio.
- CNN layers learn features such as harmonics, transients and envelopes.
- The final encoder output is a bottleneck: a compact version of the input.

$$\text{input waveform → learned analysis → latent representation}$$

# Training the autoencoder
- Training loss: MSE or waveform-spectral distance
- Perceptual loss: Encourages less-audible differences
- Optimization uses **backpropagation** and **gradient descent**

# Residual Vector Quantization (RVQ)
1. Map the input vector to the nearest code vector in a learned codebook. 
2. Compute the residual between the input and the selected code vector. 
3. Quantize the residual with another codebook. 
4. Repeat across several layers to refine the approximation

```ad-info
RVQ is the key quantization mechanism used by SoundStream and EnCodec.
```
